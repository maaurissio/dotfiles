# Mis keybinds (para portar a Omarchy)

Cambios propios sobre Caelestia (`.config/caelestia/hypr-vars.lua`, `hypr-user.lua`):

| Acción | Atajo |
|---|---|
| Terminal | SUPER + Q |
| Cerrar ventana | SUPER + W |
| Navegador | SUPER + B |
| Maximizar (respeta barra) | SUPER + M / SUPER + ALT + F |
| Pantalla completa | SUPER + F |
| Wallpaper aleatorio | SUPER + R |
| Mouse | accel_profile flat |

Resto de base Caelestia: SUPER+1..0 workspace, SUPER+ALT+1..0 mover ventana,
SUPER+flechas foco, SUPER+SHIFT+flechas mover, SUPER+Z/X mover/redimensionar,
SUPER+P pin, SUPER+E archivos, SUPER+C editor, SUPER+V portapapeles,
SUPER+L lock, SUPER+SHIFT+S captura, SUPER+. emoji.
Lista completa: `.config/hypr/variables.lua` (vars `kb*`).
