# dotfiles

Rama `arch-caelestia`: Arch + Hyprland (Lua) + Caelestia shell.
La rama `main` es la config anterior (hyprland.conf clásico).

- `.config/` -> copiar a `~/.config`
- `packages/` -> `pacman -S --needed - < packages/pkglist-native.txt`; AUR con paru/yay
- `system/DRIVERS.md` -> hardware y drivers
- `KEYBINDS.md` -> mis atajos (para portar a Omarchy)
